WH40KINGS — иллюстрации игровых карт

Папка assets/ui/card_art содержит 63 иллюстрации по ID из CARD_ART_NEEDED.txt. Все иллюстрации и рубашки имеют размер 360×504 PNG RGBA; рамки — 360×504 PNG RGBA с прозрачным окном; значки мастей — 32×32 PNG RGBA.

Файлы:
- back_space_marines.png, back_chaos.png — рубашки карт фракций.
- frame_common.png, frame_rare.png, frame_epic.png — пустые рамки редкости.
- suit_squad.png, suit_building.png, suit_upgrade.png, suit_event.png — значки мастей.
- Остальные PNG — отдельные арты карт. Имена совпадают с игровыми ID.

Арты построены по мотивам ранее созданных игровых спрайт-листов персонажей и зданий. Текст, индексы и стоимость на иллюстрации не нанесены.
